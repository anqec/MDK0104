# Практическая работа №6 — React Native + TypeScript

Исходники трёх упражнений из методички:
- Статья (`screens/ArticleScreen.tsx`)
- Диспетчер задач (`screens/TasksScreen.tsx`)
- Квадрант (`screens/QuadrantScreen.tsx`)

## Инструкция

1. Установите Node.js и создайте проект Expo:

   ```bash
   npx create-expo-app@latest PracticalWork6 --template blank-typescript
   cd PracticalWork6
   ```

2. Скопируйте `App.tsx`, папку `screens` и два PNG из этой папки в созданный проект с заменой одноименных файлов. Если оригинальные изображения даны преподавателем, используйте **их** вместо демонстрационных PNG, не меняя названий.
3. В `App.tsx` измените `ACTIVE_SCREEN` на `1`, `2` или `3` для выбора нужного упражнения.
4. Запустите:

   ```bash
   npx expo start
   ```

5. Откройте Expo Go на телефоне и отсканируйте QR-код либо запустите подходящий эмулятор.

## Примечание об изображениях

PNG в папке — **заменяемые демонстрационные изображения**, созданные для того, чтобы пример запускался без отсутствующих оригинальных файлов. Изображения из методички с теми же именами лучше получить от преподавателя; они могут иметь другой внешний вид.

Зависимости и настройки Expo задаются генератором `create-expo-app` и не включены в эту папку.
